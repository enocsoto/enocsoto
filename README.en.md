I've been building APIs and web apps since 2015. I started with Node.js and Express on aircraft maintenance systems; today I build **Java 17/21** APIs and **Next.js** interfaces at Kenility. Along the way I led backend teams on **NestJS**: setting technical scope, wiring microservices into monoliths and keeping the architecture consistent sprint after sprint.

### What I do well

- **REST APIs & microservices** — NestJS, Express, Java · JWT, RBAC · Swagger
- **Data** — PostgreSQL, MySQL, MongoDB, DynamoDB, OpenSearch · TypeORM, Sequelize, Mongoose
- **AWS & serverless** — Lambda, API Gateway, SQS/SNS, EventBridge, ECS, S3 · Docker, CI/CD
- **Quality** — unit and E2E testing, TDD, SOLID, Repository pattern
- **Frontend** — React, Next.js, Redux, Angular
